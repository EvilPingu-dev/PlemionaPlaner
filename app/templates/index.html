⚙ Jednorazowa konfiguracja – automatyczne wypełnianie wiadomości

Aby przycisk ✉ Wyślij w TW automatycznie wypełniał odbiorcę, temat i treść, wykonaj trzy kroki:

1
Zainstaluj rozszerzenie do skryptów w swojej przeglądarce:

Zalecane: Violentmonkey (Chrome/Edge) i Greasemonkey (Firefox)

🟢 Violentmonkey – Chrome 🟢 Violentmonkey – Edge 🦊 Greasemonkey – Firefox 🟢 Violentmonkey – Firefox 🟡 Tampermonkey – Chrome
2
Zainstaluj skrypt – wypróbuj oba sposoby:
⬇ Auto-instalacja (kliknij)

Otwórz Violentmonkey → kliknij + (nowy skrypt) → zaznacz wszystko i wklej poniższy kod → Ctrl+S aby zapisać:

3
Chrome: włącz userscripts (jednorazowo)
  1. Kliknij ikonę puzzla (Rozszerzenia) na pasku Chrome → trzy kropki obok Violentmonkey → Zarządzaj rozszerzeniem
  2. Na stronie szczegółów znajdź przełącznik „Zezwalaj na skrypty użytkownika" / „Allow user scripts" i włącz go
  3. Chrome wyświetli ostrzeżenie bezpieczeństwa – kliknij Zezwól / Allow (to normalne dla wszystkich skryptów użytkownika)
  4. Wróć na stronę Tribal Wars, odśwież ją i sprawdź czy ikona Violentmonkey pokazuje aktywny skrypt

Po wykonaniu obu kroków przycisk ✉ Wyślij w TW będzie automatycznie wypełniał formularz wiadomości w grze. Konfiguracja jest jednorazowa.

🤖 Discord – Przypomnienia wysyłek

Bot wyśle wiadomość na kanał Discord X minut przed każdą wysyłką z rozpiski.
Potrzebujesz: tokena bota (Discord Developer Portal) + ID kanału.

Jak skonfigurować bota? (krok po kroku)

  1. Wejdź na discord.com/developers/applications (zaloguj się kontem Discord)
  2. Kliknij niebieski przycisk New Application → wpisz nazwę np. PlanerAkcji → Create
  3. W lewym menu kliknij Bot
  4. Kliknij Reset Token → potwierdź → skopiuj token (długi ciąg liter/cyfr) → wklej go powyżej w pole Token bota
  5. Na tej samej stronie przewiń w dół do Privileged Gateway Intents → włącz Message Content Intent
  6. W lewym menu kliknij OAuth2 → OAuth2 URL Generator
  7. W sekcji Scopes zaznacz: bot
  8. W sekcji Bot Permissions która się pojawi zaznacz: Send Messages
  9. Na dole strony skopiuj wygenerowany URL i otwórz go w przeglądarce
  10. Wybierz swój serwer Discord z listy → kliknij Authorize → potwierdź captcha
  11. Bot pojawi się teraz na liście członków serwera
  12. ID kanału: w Discordzie: Ustawienia → Zaawansowane → włącz Tryb dewelopera → prawy klik na kanał → Kopiuj ID kanału

Po skonfigurowaniu: wklej token + ID kanału powyżej → Zapisz → Uruchom bota → Wyślij test
